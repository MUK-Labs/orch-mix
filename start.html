Three ways to begin

01 · TRY IT NOW

Explore the controls

Open the mixer and choose Try the sound demo. It creates sound on your computer, so you can try playback, faders, solo, mute and the balance challenge immediately.

Synthetic demonstration audio; no orchestral recording is bundled.

02 · BRING A RECORDING

Download once. Play locally.

Download a set of synchronized stems below. Choose Load stems → Choose folder, select a passage and press Open excerpt. Keep a session template beside the stems to restore labels and seating.

03 · TAKE IT OFFLINE

Keep a copy

Download Orch Mix (ZIP), extract it and open index.html for ordinary playback. No recordings are included. For saved folders and MIDI offline, use the optional local launcher.

Start with Operation Beethoven

Beethoven’s Fourth Symphony, first movement, performed in twelve synchronized section tracks by the Hofkapelle München. Download all twelve WAV files into one folder. If your browser opens an audio player, use its download menu or save the link.

WAV is the simplest full-length option: Orch Mix reads only your selected passage. Full-length MP3/FLAC files need conversion or trimming first because browser decoding uses much more memory.

  1. Put the downloaded beethoven-operation.orchmix.json beside the twelve WAVs; keep their original filenames. Do not include the separate tutti recording.
  2. Open Orch Mix, choose Load stems → Choose folder and select that folder. The template supplies names, seating and player counts.
  3. Choose a start time and length (try 30 seconds), then Open excerpt and press Play.
  4. For quick access next time, use Remember folder in desktop Chrome or Edge and allow read access when asked.

Make it a listening exercise

  • Build the orchestra: press All off, then introduce sections individually with the stage map or Random instrument.
  • Balance by ear: select Balance challenge, adjust the faders, then Reveal balance to compare with the reference.
  • Guess the piece: remember several folders with one session JSON each, then use Random excerpt. Reveal piece shows the answer.
  • Hands on: connect a MIDI controller and learn up to 16 faders/knobs per bank, plus Play / pause, All off / restore and Random instrument.

Your files stay with you

The site loads the app; you choose which local files it can read. Audio is processed in the browser and is never uploaded. Session downloads contain settings and filenames only. Publisher links open separately; their terms apply to the recordings.

The online site and localhost keep separate saved folders and MIDI mappings. Add your folders and learn your controller once on the online site. Use the same browser profile and address on later visits. Browsers without remembered-folder or MIDI support can still use ordinary file loading and the on-screen mixer.

The site does not install an offline cache. For use without internet, download the ZIP above. Long recordings are best used on a desktop with short excerpts.
